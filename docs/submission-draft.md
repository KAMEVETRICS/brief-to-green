**Project title:** Brief→Green

**Short description:**
Turn a product brief into a green, tested feature with IBM Bob 2.0 — Plan mode, parallel Agent/subagents, and session-proof evidence.

**Long description:**
Brief→Green attacks the costly gap between written product briefs and merge-ready code. During the IBM Bob 2.0 hackathon we use Bob’s document understanding and Plan mode to scope a real feature from a brief, then Agent mode with subagents and parallel tasks to implement and test it on a sample board app. The Brief→Green dashboard narrates plan → parallel work → green status, and we submit Bob task session summary screenshots as proof. Impact is measured as fewer manual translation steps and faster time-to-green on a concrete feature.
