# Demo script (2–4 min)

1. **Hook (15s)** — “Briefs die in ticket backlogs. Brief→Green turns a written brief into a green, tested change with IBM Bob 2.0.”
2. **Problem (20s)** — Show sample-board missing the feature; count manual steps today.
3. **Brief (20s)** — Open `briefs/sample-feature-brief.md` (or DOCX). Drop into Bob / Brief→Green.
4. **Plan (30s)** — Bob Plan mode output on screen; highlight scoped steps + acceptance checks.
5. **Parallel execute (45s)** — Agent + subagents: implement lane + test lane running; point at Bob UI.
6. **Green (30s)** — Live sample-board with feature working; tests passing; Brief→Green dashboard green.
7. **Evidence (20s)** — Flip through Bob task session summary screenshots.
8. **Impact (20s)** — Before/after: wall-clock and error/rework reduction claim with honest numbers from this build.
9. **Close (10s)** — Repo + demo URL; KAMEVETRICS / IBM Bob 2.0.
