# Demo script — Brief→Green (2–3 minutes)

**Audience:** IBM Bob 2.0 hackathon judges  
**Tone:** crisp, metric-led, Bob as the spine  
**Target:** **2:30** (hard cap 3:00)

---

## Shot list

| # | Time | On screen | Voiceover |
|---|------|-----------|-----------|
| 1 | 0:00–0:20 | Title + problem | “Briefs stall between spec and ship. Serial handoffs and no provenance kill release speed.” |
| 2 | 0:20–0:45 | sample-board **BEFORE** (gap banner, empty filter slot) | “Sample Board already has priority and due dates in the data — but no filter and no badges. That’s our gap.” |
| 3 | 0:45–1:15 | Bob **Plan** on the brief + session summary | “We drop the brief into IBM Bob Plan. Bob scopes steps, acceptance, and parallel lanes.” |
| 4 | 1:15–1:55 | Bob **Agent + subagents** (UI / logic / tests) | “Agent fans out three subagents in parallel — UI badges, filter logic, tests — not serial coding.” |
| 5 | 1:55–2:20 | sample-board **AFTER** + brief-green green + metrics | “Board is green: filter works, badges show. Dashboard: plan → lanes → metrics → checklist.” |
| 6 | 2:20–2:40 | `docs/bob-sessions/` collage + end card | “Full Bob session provenance for judges. Brief→Green — code on GitHub.” |
